# Snake Game

A simple Snake Game developed using **C# and Windows Forms**.

This project was built as a practical application of programming concepts I have been learning, including:

* Object-Oriented Programming (OOP)
* Collections using `List<Point>`
* Event-driven programming
* Timer-based game loops
* Keyboard input handling
* Collision detection
* Dynamic snake movement and growth
* Windows Forms controls and UI interaction
* Git and GitHub for version control

The project also helped me understand how to separate the game logic from the user interface and how different components interact within a Windows Forms application.
